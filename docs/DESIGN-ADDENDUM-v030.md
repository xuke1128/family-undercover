## 2. 变更一：出局揭晓只亮身份、不亮词（PRD §9 第 14 项）

### 2.1 P8 两段式的新交互定义（RevealView → 界面图 p08a / p08b）

- **第一段「亮人」（p08a，不变）**：大头像 + 名字放大（「出局的是……爸 爸」），按钮「✦ 翻开身份 🎴 ✦」进入第二段。
- **第二段「亮身份」（p08b，按本变更重画）**：
  - 紫色身份卡（卧底出局）只含三要素：**出局者头像、名字、「🎭 卧底！」大字**；卡上与整屏任何位置不得出现词语或「他的词：××」句式；
  - 卡片下方固定一行小字：「词语会在终局揭晓，别急 👀」——向孩子解释为什么不亮词，并预告终局有答案；
  - 按钮保持「继续 ▶」，点击后按胜负判定推进（未分胜负 → 下一轮投票）；
  - 平民出局为同构变体：薄荷绿卡片 +「🌱 平民！」，同样不亮词。
- 揭晓页文案口径：只允许出现身份词（卧底/平民）与保密提示，不得泄露词对中任何一个词。

### 2.2 与 P10 终局词对照的关系（FinalView → 界面图 p10-result）

- **词语的唯一公开时机 = 终局结算页**：顶部两枚胶囊「平民词：饺子 🥟 / 卧底词：包子」+ 玩家列表每行「词语：××」；p10-result **按新规则保留，无需改动**（此时一局已结束，公开词对无泄密问题）；
- 词语可见性在三个环节单调递增，P8 是其中唯一「亮人亮身份、不看词」的环节：
  1. P4 看词：每人只见自己的词，隐藏后无任何残留；
  2. P8 出局揭晓：只亮身份，不亮词；
  3. P10 终局结算：平民词/卧底词对照全公开。

## 3. 变更二：看词与投票顺序随机（PRD §9 第 15 项）

### 3.1 P4 看词交接卡（PeekView → p04a/b/c，不重画，口径如下）

- 看词顺序 = **每局开局随机生成一次**，与名单添加顺序无关，本局内不变；
- 顶部进度头像条按该局看词顺序排列：当前者放大橙描边、已完成绿 ✓、未开始灰描边；右上角计数「看词 n/N」；
- 界面不得出现「按名单顺序」的暗示文案；交接主文案仍是「下一个是 + 名字 + 头像」。

### 3.2 P6 投票交接卡与候选卡（VoteView → p06，不重画，口径如下）

- 每一轮的投票顺序**在该轮开始时重新随机打乱**（与名单顺序、看词顺序均无关）；
- 交接卡与候选卡网格（2 列）均按**本轮随机序**展示；候选人 = 除自己外的存活玩家；
- **平票重投沿用本轮顺序**：重投轮顶部标注「🔄 重新投票 · 可以换票」，头像条与候选卡不重排；
- **进入新一轮才重排**：顶部横幅「第 N 轮 · 还剩 X 人」，头像条按新一轮随机序重新排列；
- **出局者移除**：候选卡不再出现出局者；头像条同步移除出局者；页面底部保留一行「已出局：××（不可选）」灰显提示；
- 展示口径一句话：**头像条/候选卡的排列 = 当前轮随机序；轮次标注只讲「第几轮 / 还剩几人 / 可换票」，不向用户解释随机机制。**
