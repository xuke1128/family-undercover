# 家庭卧底派对（Family Undercover）

> 一台手机传着玩的合家欢「谁是卧底」——免下载免登录、断网可玩、儿童适宜词库，5 到 50 岁一秒上手。

纯前端静态单页应用（Vite + React + TypeScript）：**零后端、零运行期网络请求、零密钥**，战绩只存本机 localStorage。打开链接即可开一局；访问过一次后，Service Worker 离线缓存让全家在无 Wi-Fi / 弱网环境照样畅玩。

## 功能亮点

- **开箱即玩**：无下载、无注册、无广告。打开即默认**简单模式**（3-6 人，儿童词库），局前可切换**普通模式**（3-12 人）
- **传机防偷看**：看词前须本人确认「是我」，隐藏后词语立即从界面消失、不可回看；局内单向线性流程、无返回导航；中途刷新即作废本局
- **完整规则引擎**：卧底数自动映射（普通模式 3-7 人 1 名 / 8-12 人 2 名，简单恒 1 名）、看词后直接进入逐人秘密投票（App 不做逐人描述引导，家人面对面自由交流）、票型全公示、平票全员直接重投一次（可换票，仍平票则本轮无人出局）、连续 3 轮无人出局的兜底重开、胜负判定与计分全自动化
- **110 对儿童适宜词库**：5 分类 × 2 难度，清单即代码（[`src/game/wordBank.ts`](src/game/wordBank.ts)），逐条人工审核，无成人向 / 暴力 / 恐怖 / 商标词，并有自动化黑名单兜底；连局自动避开近期用过的词对
- **54 个头像**：4 个本项目**原创 SVG 形象**（暖爸 / 甜妈 / 像素小子 / 粉兜兔）+ 50 个 emoji；已被选头像即置灰，🎲 一键随机互不重复
- **本机战绩排行榜**：按胜场 → 胜率排序；「再来一局」沿用名单与模式、自动换新词；清空战绩有二次确认
- **移动端与无障碍基线**：主按钮 ≥56px / 传机按钮 ≥64px 触控目标、`100dvh` + 手势条安全区适配、`prefers-reduced-motion` 动效降级

## 玩法规则速览（照此即可开一局）

1. **看词**：手机按座位顺序传递，轮到谁谁点「是我，看词」，看完点「记住啦，隐藏」传下一位（隐藏后不可回看）
2. **交流**：全员看完词后大家面对面聊一聊（不要说出词语本身），节奏自定
3. **投票**：传机逐人投票（候选不含自己与已出局者），全员投完公示得票与票型
4. **出局**：得票最高者出局亮身份与词；平票则全员直接重投一次（可换票），仍平票本轮无人出局
5. **胜负**：卧底全出局 → 平民胜；存活卧底数 ≥ 存活平民数 → 卧底胜
6. **战绩**：获胜阵营全员（含已出局者）各 +1 胜，全体 +1 局，按「昵称 + 头像」存本机

## 部署

纯静态产物（`dist/`，Vite `base: './'` 相对路径），任意静态托管可用：

- **GitHub Pages**（本仓库默认）：push 到 `main` 自动经 [deploy-pages 工作流](.github/workflows/deploy-pages.yml) 构建并发布 `dist/`；首次使用需在仓库 **Settings → Pages → Source 选择 "GitHub Actions"**
- **Vercel**：零配置，Framework Preset 选 **Vite**（Build Command `npm run build`，Output `dist` 自动识别），无需 `vercel.json`
- **其它**（Netlify / Cloudflare Pages / 自建静态服务器）：上传 `dist/` 目录即可

生产构建自带 Service Worker（cache-first）：访问过一次后完全断网可玩。首次打开需有网络，属 Web 平台固有限制。
